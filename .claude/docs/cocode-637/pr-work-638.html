판단과 연결 경계

supported는 역할 lookup과 요청된 primitive adapter 타입의 의미다. 전체 PRD·앱·고정 투어·배포·FSM을 통과했다는 뜻으로 사용하지 않는다. 일반 scalar 대신 DateTime·coherent DTO를 제공하며, compound series의 primitive adapter는 진짜 JSON이고 잘못된 숫자 타입 요청을 거부한다.

스키마96개는 예시다. 정확한 앱 건수/가중 분포, 고정 투어 ID, owner별 이력, 합계·한도·추첨, 전체 관계 그래프는 레시피/소비자의 조립 계약이다. 문제은행은 직접 쓴 일반 IT 템플릿9종과 결정적 선택지 변형이며, 120개의 독립 문제를 공급했다고 주장하지 않는다.

기존 SaaS/clinic 코드 집합은 변경하지 않았다. 특정 PRD의 조건부 재사용은 명시적 recipe enum/adapter로 연결한다. 새로운 작성 데이터의 curated denylist는 보편적인 실존명/상표 검증을 뜻하지 않는다.
