왜 이렇게 했나

1. 안전망 먼저, 호출마다 새 생성기

CoFakerClinic 86개 · CoFakerSaas 37개 공개 멤버(데이터 접근자 제외 전수, 일회성 mirrors 스크립트로 빠진 것 0 확인)를 기본 인자와 대표 인자로 호출해 digest(64비트)와 표본을 고정했다. 가중 분기(건강 점검 · 감사 대상 · 결제 수단)는 반복해서 모든 분기를 지난다. 호출마다 새 생성기를 써서 한 호출의 난수 소비 변화가 뒤 호출로 번지지 않는다. ko · en 은 seed 3종, 영어/한국어로 폴백하는 15개 코드(ja_JP · zh_TW · xx_YY …)는 한 seed. 변이 3건(원 포인트 단위 · 선불 지갑 최소 사용액 · 영어 날짜 서식)이 실패로 잡히는 것을 확인했다.

2. 한국 전용 값은 세 갈래 — CoKoreanValues

이슈의 예(koreanIdentity + 레거시 플래그)는 두 불리언이지만 유효한 조합은 셋뿐이라(한국 전화/주소만 쓰고 주민번호는 안 쓰는 데이터는 의미가 없다) 열거형 하나로 묶었다. korean = ko, legacy = 영어와 새 필드를 비운 사용자 정의 데이터(기본값), none = 새 언어. legacy 는 영어가 늘 내던 값(주민번호 마스킹 · 8자리 승인번호 · 마스킹 현금영수증 · 사업자번호 · 한국 공휴일)을 그대로 낸다.

버린 대안: 불리언 둘 — 의미 없는 조합이 생긴다. 로케일 코드를 선택 로직으로 옮겨 계속 쓰기 — "코드가 아니라 데이터가 정한다"는 목표와 어긋난다.

3. 중립 대체(none)의 정의

전화는 internet.phoneNumber(), 주소는 국가 로케일이면 postalAddress()(addressLineFormat 으로 우편번호를 뺀 주소 줄, 언어 전용 로케일이면 단순 주소), 환자 ID 는 maskedIdFormat 템플릿, 사업자번호는 businessNumberFormat, 카드는 평범한 6자리 승인코드, 현금영수증 번호 없음, 휴진 안내에 공휴일 없음. 안전망의 clinic · saas 호출 전수를 가상 일본어/독일어 데이터로 돌려 한글과 한국 형식(주민번호 마스킹 · 010 · 사업자번호)이 0 임을 테스트가 고정한다.

4. 금액 · 서식은 const 값 객체, 기본값은 영어

CoCurrencyFormat 의 pattern({symbol}{amount} · {amount} {symbol} · {symbol} {amount})과 구분자 · 소수 자릿수로 ¥1,234 · 1.234,00 € · R$ 1.234,00 · 1 234,00 ₽ 를 데이터만으로 쓴다. 코드 · 기호 · 소수 자릿수가 국가 데이터와 맞는지는 표 테스트와, 레지스트리에 들어온 언어 데이터에 자동으로 걸리는 가드가 본다(영어 $1,234 는 정수 달러 표기라 예외). 규모는 _korean ? A : B 쌍 전부(10000:10 · 500000:500 · 50000:50 · 1000:1 · 100:1 · 1000:5)에 더해 부가세율과 선불 지갑 금액까지 필드로 뽑았다 — 독일어 19% 같은 값이 코드 수정 없이 들어가야 하기 때문이다. 모든 새 필드에 기본값이 있어 기존 사용자 정의 데이터는 그대로 컴파일되고 같은 출력을 낸다.

5. 문구는 템플릿 필드, 누락은 영어로 폴백

회/x · @이름님 · 설/추석 연휴명 · 날짜 · 응답 지연/연결 시간 초과 · 대표번호/예약 문의 · 계정/직원 권한/알림톡/환자·차트·수납·예약을 {name} · {role} · {month} 같은 템플릿과 목록/맵 필드로 옮겼다. 비어 있으면 영어, 맵은 키 단위로 영어 폴백한다(리뷰 반영).

6. 레지스트리는 "파일이 슬롯"

CoL10nClinic.entries 는 한 const 맵이고 항목마다 빈 줄로 나뉜다. 항목이 읽는 zhClinic 같은 상수가 <lang>_clinic.dart 의 null 스텁이라, 언어 Story 는 자기 파일의 null 만 const CoFakerClinicData(...) 로 바꾼다(레지스트리 · 테스트 수정 없음). 스크래치 복사본에서 zh 스텁만 채워 zh · zh_CN · zh-Hans-CN · forLanguage('zh-Hans') 가 중국어 데이터를, zh_TW · zh_HK · zh-Hant · 스텁 언어는 영어를 받는 것을 확인했다. 선택은 로케일 자신의 데이터 → 레지스트리 → 영어이고, CoFakerLanguages.resolve(locale).supported 가 false(번체 · 지원 밖 · 커스텀 코드)면 레지스트리를 건너뛴다.

7. 영어에 남은 불편한 사실은 보존했다

영어 SaaS 선불 지갑은 원 규모 숫자(10만~500만)이고, 영어 휴진 안내는 어린이날 같은 한국 공휴일을 한국어 이름으로 낸다. 둘 다 바이트 동일 계약 때문에 legacy 값으로 보존했고 dartdoc 에 적었다. 영어 견적 대역(quoteMin/Max)만은 내장 데이터가 닿지 않는 경로라 달러 규모(50~300)로 바로잡았다.
