왜 이렇게 했나

1. 정렬이 계약이다

한 곳도 순서를 바꾸지 않았다. 영어가 한국어 음차로 쓴 가상 이름(Solbit · Garam · Mulpare · Solnae · Ginkgo …)은 같은 자리에 같은 한 가지 일본어 가상 지명(ひなたが丘 · せせらぎ台 · とねりこ町 · 松川町 · いちょう町)으로 옮겨 번들 전체에서 일관되고, 모두 （架空） 나 架空市 가 붙는다. 예시는 （例） 한 가지다.

2. 표기 · 문체 · 서식 (AC)

문체는 です・ます 한 가지이고 소설 단락의 서술도 포함한다(처음에는 평어체 だ・である 로 썼다가 AC 를 예외 없이 지키려 고쳤고, 테스트가 문장 단위로 확인한다). 숫자는 반각, 가타카나는 전각(반각 금지), 조수사는 回 · 名 · 件, 날짜는 10月8日（木）, 금액은 ¥1,200. 한자 · 가나 흔들림은 용어집에서 한 가지로 정했다(受付 · 見積もり · か月 · 取り扱い · ごはん · すべて …).

3. 엔 규모

시술 가격대는 일본 미용 클리닉의 세금 포함 가격(초진 3,000~6,000 · 피코토닝 10,000~30,000 · HIFU 60,000~250,000 …), 반올림은 시술 500 · 회수권 1,000 · 할인 · 분할 · 포인트 10, SaaS 월 요금은 ¥9,800 · ¥19,800 · ¥34,800 · ¥69,800. 한국 전용 값은 없다(koreanValues: none).

4. 영어 한 단어가 두 일을 가리키는 곳

Consultation 은 진료 단계의 診察, 방문 목적과 상담 대본의 カウンセリング, 세무 · 법률 상담의 相談 으로 나눴고 용어집에 행을 따로 둔다. Package 는 回数券(コース 금지), Split payments 는 併用 이다(分割払い 는 할부라 틀린 뜻). Cancelled 는 예약이면 キャンセル, 구독이면 解約済み.

5. 안전 · 상표

수의 · 어린이집의 약 이름에는 （架空） 를 달았고(clinic 의 약 이름 줄기는 영어처럼 지어낸 이름이다), 보툴리눔 제제는 상표를 피해 ボツリヌストキシン, Instagram ad 는 SNS広告 로 옮겼다. 카드 브랜드(Visa · Mastercard · Amex)는 영어 데이터와 같은 자리에 있고 Discover 자리는 JCB 다. 알림 템플릿의 #{변수} 는 영어 이름 · 개수를 지켰다.

6. 테스트가 막는 것

인덱스 정렬 검사만으로는 두 번역이 서로 뒤바뀌어도 통과한다(같은 목록을 읽고 비교하므로). 그래서 영어 문구와 일본어 번역의 짝 55쌍을 같은 위치에 있는지로 확인하는 앵커 시험을 두었다. 변이 시험 10종(뒤바뀐 번역 · 달러 규모 반올림 · 반각 괄호 · 반각 가타카나 · 평어체 문장 · koreanValues · 잃은 #{변수} · 날짜 서식 · 조수사 · 소비세율)을 하나씩 넣어 각각 테스트가 잡는 것을 확인했다.

알려진 한계 · 범위 밖

  • 한국식 숫자 형식(clinic.approvalNo · saas.recipient · rrnMasked · businessNumber)과, korea 팩이 켜졌을 때 entity 의 phone · address1 은 모든 언어에 한국식이다. 한글이 없어 게이트가 못 보고 언어 파일로 못 고친다(S3 소관).
  • CoClinicHours 기본값은 한국 피부과 영업시간이고 clinic.inquiry() 는 로케일과 무관하다. 생성기가 쓰는 ASCII 구두점(尋常性ざ瘡 (L70.0))은 언어 파일로 못 바꾼다.
  • CoFaker(locale: 'ja') 는 국가가 없어 환자 주소가 기본 모듈의 일반 주소다(forLanguage 와 ja_JP 는 東京都…). 도메인 데이터는 같다.
  • 용어집의 금지 표기는 부분 문자열로 맞춰서, 번역의 앞부분인 변이형(プリンタ 대 プリンター)은 금지할 수 없다. 장음 표기는 서식 칸의 규약으로만 둔다.
  • 가격대는 일본 미용 클리닉을 가정한 추정치라 원어민 검토 대상이다. CHANGELOG · README · 공유 파일은 고치지 않았다.

후속 Story 가 알아야 할 것

  • 위치 앵커 시험(_anchors)은 언어마다 짝 수십 개로 옮겨 쓸 수 있다. 인덱스 정렬만으로는 잡히지 않는 뒤바뀐 번역을 잡는다.
  • 한 영어 단어가 두 일을 가리키면 용어집 행을 둘로 나누고, 번역의 앞부분인 금지 표기는 쓰지 못한다는 점을 미리 본다.
